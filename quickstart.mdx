## Get Started in Three Steps

Start using the Finster API to query company data sources and execute research tasks.

### Step 1: Get Your API Key

<AccordionGroup>
  <Accordion icon="key" title="Obtain your API key">
    Contact Finster support to obtain your API key. You'll need this key to authenticate all API requests.
    
    Once you have your API key, keep it secure and never expose it in client-side code or public repositories.
  </Accordion>
</AccordionGroup>

### Step 2: Make Your First Query

<AccordionGroup>
  <Accordion icon="code" title="Execute a query">
    Here's a simple example using curl to execute a query:

    ```bash
    curl -X POST "https://api.finster.ai/api/public/v1/queries?user_id=user_12345" \
      -H "X-API-Key: your_api_key_here" \
      -H "Content-Type: application/json" \
      -d '{
        "user_query": "What did Tesla say about their Q4 2024 earnings in their SEC filings?"
      }'
    ```

    This will return a structured JSON response with the answer, citations, and source information.
  </Accordion>
  
  <Accordion icon="filter" title="Specify data sources">
    You can limit your query to specific data sources:

    ```bash
    curl -X POST "https://api.finster.ai/api/public/v1/queries?user_id=user_12345&data_sources=SEC_FILINGS&data_sources=INVESTOR_RELATIONS_DOCUMENTS" \
      -H "X-API-Key: your_api_key_here" \
      -H "Content-Type: application/json" \
      -d '{
        "user_query": "What did Tesla say about their Q4 2024 earnings?"
      }'
    ```

    Available data sources:
    - `SEC_FILINGS` - SEC filings and regulatory documents
    - `INVESTOR_RELATIONS_DOCUMENTS` - Investor relations materials
    - `INDUSTRY_RESEARCH` - Industry research reports
    - `WEB_SEARCH` - Web search results
  </Accordion>

  <Accordion icon="stream" title="Use streaming mode">
    For real-time responses, enable streaming:

    ```bash
    curl -X POST "https://api.finster.ai/api/public/v1/queries?user_id=user_12345&stream=true" \
      -H "X-API-Key: your_api_key_here" \
      -H "Content-Type: application/json" \
      -d '{
        "user_query": "What did Tesla say about their Q4 2024 earnings?"
      }'
    ```

    This returns Server-Sent Events (SSE) stream with incremental updates.
  </Accordion>
</AccordionGroup>

### Step 3: Execute a Task

<AccordionGroup>
  <Accordion icon="rocket" title="Submit a research task">
    For longer research tasks, use the tasks endpoint:

    ```bash
    curl -X POST "https://api.finster.ai/api/public/v1/tasks/execute" \
      -H "X-API-Key: your_api_key_here" \
      -H "Content-Type: application/json" \
      -d '{
        "user_id": "user_12345",
        "task_description": "Analyze Tesla'\''s Q4 2024 earnings performance compared to analyst expectations",
        "research_focus": "Tesla, Inc.",
        "data_sources": ["SEC_FILINGS", "INVESTOR_RELATIONS_DOCUMENTS"],
        "output_format": "detailed"
      }'
    ```

    This returns a `task_run_id` that you can use to check status and retrieve results.
  </Accordion>

  <Accordion icon="clock" title="Check task status">
    Poll the status endpoint to track progress:

    ```bash
    curl "https://api.finster.ai/api/public/v1/tasks/runs/{task_run_id}/status?user_id=user_12345" \
      -H "X-API-Key: your_api_key_here"
    ```

    Poll every 5-10 seconds until the status is `complete`.
  </Accordion>

  <Accordion icon="file-lines" title="Retrieve results">
    Once the task is complete, retrieve the results:

    ```bash
    curl "https://api.finster.ai/api/public/v1/tasks/runs/{task_run_id}/result?user_id=user_12345" \
      -H "X-API-Key: your_api_key_here"
    ```

    This returns the complete generated report with citations and research plan.
  </Accordion>
</AccordionGroup>
