## API Endpoints

### Queries
Execute real-time queries against company data sources:
- **POST** `/api/public/v1/queries` - Execute a query with streaming or single response

### Tasks
Manage asynchronous research and generation tasks:
- **POST** `/api/public/v1/tasks/execute` - Submit a task for execution
- **GET** `/api/public/v1/tasks/runs/{task_run_id}/status` - Check task status
- **GET** `/api/public/v1/tasks/runs/{task_run_id}/result` - Retrieve task results
