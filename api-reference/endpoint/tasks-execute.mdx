---
title: 'Execute Task'
openapi: 'POST /api/public/v1/tasks/execute'
---

Submit a Task for execution. The task will be queued for processing. Use the returned task_run_id to check status and retrieve results.

The system will:
1. Create a research plan based on your description
2. Execute research queries against specified data sources
3. Generate a comprehensive output in your chosen format
4. Return results with citations
